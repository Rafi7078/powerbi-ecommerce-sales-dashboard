# E-Commerce Sales Dashboard | Power BI

## Project Overview
This project presents an interactive E-Commerce Sales Dashboard developed using Power BI to analyze sales performance, profit trends, customer behavior, and product category insights.

The dashboard helps businesses monitor KPIs and make data-driven decisions for improving sales and profitability.

---

# Business Problem
E-commerce businesses generate huge amounts of sales data daily. Analyzing this data manually is difficult and time-consuming.

This dashboard helps answer important business questions such as:
- Which product categories generate the highest revenue?
- Which regions perform best in sales?
- What are the monthly sales trends?
- Which products contribute most to profit?
- How can business performance be improved?
